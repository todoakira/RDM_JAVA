# 한국 서비스 클라이언트 두 벌 (엑사토, Zeus) 확인 (2026-11-24)

## 무엇인가
두 벌 모두 사설 서버용 한국어 클라이언트다.
- **엑사토:**
  - 3944 판이다. rm3944cl.dll 이 우리 참고 클라이언트(Redmoon Advanced)의 것과 같다.
  - main.dll 은 VMProtect 로 싸여 있어 풀어 읽을 수 없다.
  - 빌드 시각(0x3da788f8, 2002-10)은 우리 참고본과 같다.
  - rm3944cv.dll 은 PE 가 아니다 (암호화된 것으로 보인다).
  - ddraw.dll 은 cnc-ddraw 감싸개다.
- **Zeus:**
  - Main.dll 은 싸여 있지 않다. 빌드 시각이 2004-07-12 로, 우리 판(2002)보다 나중의 공식 클라이언트다.
  - 2004 판에서 새로 생긴 것: 창고 창(iw_wc_*, iw_wi_*), chatlog 등.
  - 우리 판(3944)과 판이 달라 주소를 그대로 맞대 볼 수는 없다.
  - myplus/mxplus/mzplus.dll 과 myplus.pdb 는 2024년에 만든 팬 확장이다.
    - My_Grow, My_Item, My_Event 따위이고, MFC 로 짰다.
    - 원작 구조를 알려 주는 것은 없다.
  - config.dll, MyPlus.ini, skilledit.exe, ITEM.TXT 도 사설 서버 운영 도구다.

## 쓸 만한 것: 한국어 글자 자료 (Message.ctf)
- 두 벌의 Message.ctf 는 한국 서비스 원문이다.
  - 같은 번호에 엑사토와 Zeus 의 글이 2701 개 중 2571 개 같다.
- 번호도 지금 쓰는 영어판(Redmoon Advanced)과 뜻이 맞는다. 견주어 본 예:
  - 0/2/9 쓰러짐
  - 0/2/97 지정 구매자
  - 0/0/175 Buyer 안내
  - 2/x 기술
  - 4~8 묶음 아이템
  - 0/5 직업·NPC
  - 0/6 지역
- 영어판은 한국어 원문을 옮긴 것이다. 그래서 이제 **한국어를 기본 글자 자료로 쓴다** (`tools/korean_messages.js`).
  - 번호마다 엑사토 → Zeus → 영어 순으로 고른다. 비었거나 "blank" 면 다음으로 넘어간다.
  - 도움말(묶음 1)은 판마다 줄 나눔이 달라서 분류째로 고른다.
  - 영어 원본은 `assets/messages_en.json` 으로 남겼다.
- 결과: 한국어 3500 개, 영어로 남은 것 610 개. 남은 영어는 대부분 Redmoon Advanced 가 덧붙인 것이다.
  - 0/7 대사 535 개.
  - 묶음 9 아이템 33 개.
  - 서버 이벤트 대본이 쓰는 대사 286 개 가운데 149 개는 한국어판에 없다. 영어 그대로다.
- rm45·cl45 의 Message.ctf 는 중국어(GBK)판이라 쓰지 않는다.

## 쓰지 않는 것
- **아이템 정보(ItemNN.rmi)·기술 정보(skill00.rmi):**
  - 두 벌 모두 값이 크게 바뀌어 있다. 사설 서버에서 밸런스를 고친 것이다.
  - 6번 묶음은 Zeus 가 555 개로 늘렸다.
  - 원작 값은 계속 3944 서버 자료를 쓴다.
- **인터페이스 그림:**
  - Zeus 는 우리 참고본과 3 파일만 다르다. 캐릭터 창을 넓히고 장비 창 칸을 늘린 것으로, 사설 서버가 고친 것이다.
  - 엑사토는 74 파일이 다르다 (사설 서버 겉모양).
  - 한국 서비스에서도 그림 글자(BUY·SELL·Game Start 등)는 영어였던 것으로 보인다. 그래서 그림은 그대로 둔다.
- **맵·캐릭터 그림:** 사설 서버에서 더하거나 고친 것이라 쓰지 않는다.
