# PK 와 PK 벌칙 분석 노트

원본: `svMapServer.exe` 3944. 구현: `server/pk.js`, 연결은 `world.js` (attackCmd, 대상 공격, killPlayer, 효과 39, 교도관), `client.js` (TAB, 사람 고르기, 교도관 창).

## PK 모드 (사용자 +0x37d0: 0 꺼짐, 1 켜는 중, 2 켜짐 / 효과 비트 37)
- 클라이언트 TAB → ProcessChangePKMode 0x41bb10. 끄기는 바로. 켜기는 이미 켜는 중·켜짐이 아니면 5초(+0x40c4 = 5000) 뒤 OnPKModeTimerExpired 0x42e6b0 가 켠다.
- SendChangePKMode(3) 0x43a710: 공격받은 사람의 PK 모드를 바로 켠다 (벌칙·GM 벌칙·+0x4168 이 있으면 안 켠다).
- 클라이언트 글: 0/0/208 켜는 중, 71 켜짐, 72 꺼짐.

## 맵과 타일
맵의 기본 이벤트 = 지역 이벤트 0 (CEventInfo::GetDefaultEvent). 맵 PK 설정 +0x35d0 은 −1 로 시작, 기본 이벤트 종류 10 이면 2.
- IsPKOffTile 0x472c10: 칸의 이벤트 종류 7·5·18·19 면 PK 안 됨, 10 이면 됨. 맵 설정 0 이면 안 됨, 1·2 면 됨, 그 밖은 기본 이벤트 종류가 7·5·18·19 면 안 됨.
- IsFightTile 0x472cf0: 칸 종류 10, 맵 설정 2, 또는 기본 이벤트 종류 10.
- IsUserSafeTile 0x472ca0: 칸 종류 5·18 또는 기본 이벤트 종류 5·18.
- 기본 이벤트 종류 30 = 벌칙 맵, 두 번째 값 = 벌칙 한 번의 시간 (ms). 예: 맵 2 등 [30, 300000] (5분), 맵 87 [30, 1200000].
- 들어올 때 (0x42452c, 몬스터가 있는 맵만): 0/2/0x161 싸울 수 없음, 0x162 벌칙 있음, 0x163 벌칙 없음.

## 공격 (CMapServerServer::DoAttack 0x469dd0, 대상이 사람)
- 맞힐 수 있으려면: 공격자 PK 모드 켜짐, 두 사람 자리 모두 PK 가능, 싸움터 여부가 같음. 그리고 둘 다 싸움터가 아니면 두 사람 모두 레벨 15 초과 (Lang 2·3·4 는 20). 아니면 빗나감.
- 정당방위: 싸움터도 PK 금지 자리도 아니고, 공격자가 이미 대상에게 정당방위를 가진 게 아니면, **대상**이 공격자에게 5분(0x493e0) 정당방위를 얻고 (0/2/0xcc), 대상의 PK 모드가 켜진다.
- 안전 칸이나 PK 금지 자리(둘 다 싸움터가 아닐 때)면 공격 자체가 일어나지 않는다.
- 정당방위가 끝나면 0/2/0xcd, 접속·맵 이동 때 남은 것을 다섯씩 0xce (CLegalDefenseManager::OnTimer 0x4092e0, EnterMap 0x408e70).

## 죽음 (CMapServerClient::Dead 0x43b010)
벌칙 맵(+0x365c = 1)에서 사람에게 죽었고, 죽은 사람이 벌칙(+0x4158)·GM 벌칙(+0x4214)이 없고, 죽인 사람이 죽은 사람에게 정당방위가 없으면 죽인 사람에게 DoPKPenaltyAction 0x42d840:
- 벌칙 횟수 +0x415c +1 (최대 1000), 벌칙 시간 +0x4158 = 맵 값 × 횟수, +0x4160 = 0.
- 효과 39 (움직이기·공격·기술 막힘: ProcessUserMoving 0x43da05, ProcessUserAttack 0x43a7a2, ProcessUseSkill 0x43c357) 5000 + 200 × 횟수 ms.
- PK 모드 끔. 남은 분 0/2/0xad.
(죽은 사람의 경험치·아이템은 보통 죽음과 같다: Lang 1.)

## 벌칙 시간 (OnTimer 0x43e131~)
살아 있을 때, 맵 48~67·110~131 밖에서 흐른다. 감옥(맵 78)에서는 절반 속도.
- 벌칙 시간이 다 되면 0 → 이야기 퀘스트 확인.
- 벌칙이 없고 횟수가 있으면 +0x4160 에 시간을 더해 54,000,000 (15시간)이 되면 횟수 −1, 남은 횟수가 있고 18,000,000 을 넘으면 18,000,000 을 빼고 아니면 0.
- 벌칙 중에는 보조 퀘스트가 걸리지 않고, 첩자~첩보대장 이야기 퀘스트 준비가 아니다.

## 교도관 (이벤트 종류 43, SendOpenJailorPacket 0x41b440, ProcessMoveJail 0x41c190)
- 감옥 밖: 0/0/214 "감옥에 데려다 줄까" → 1억. 모자라면 0/2/0xae.
- 감옥(78) 안: 남은 벌칙 분이 있으면 0/0/215, 없으면 216 → 나가기: 이야기 비트 0x100 이 없으면 무료로 맵 1, 있으면 1억 (모자라면 0xaf).
- 벌칙 중 나가려 하면 0/2/0xaa (원작에서 이 검사를 어디서 하는지는 찾지 못해 서버가 막는다).

## 아직
- 기술로 사람 공격 (UseSkillAttackSingleUser 등), 싸움터·전쟁·배틀존 점수.
- 몸 그리기 효과 (클라이언트 0x10031ee3~0x10031fe2) — **별도 그림이 아니라 그리기 방식(모드, 값)을 바꾼다**. CIS 효과 비트는 +0x1a 부터 효과 번호 순서다.
  - 효과 26 또는 35: 모드 0x20, 값 += 2 (그림자 그리기 끔). 투명하게 그리는 것으로 보인다.
  - 효과 39 (PK 벌칙으로 묶임): 모드 0x620, 값 0x65 (위 투명 상태였으면 0x67).
  - 효과 18 또는 43: 모드 0x620, 값 0x33 (투명 상태면 0x35).
  - 효과 5 또는 43: 모드 0x620, 값 0x32 (투명 상태면 0x34). 43 은 위 것을 덮어쓴다.
  - 위 어느 것도 없으면 모드 0x20, 값 0xff (보통 그리기).
  - PK 모드 비트(37)는 이 표에 없다. PK 모드 켜짐은 몸 그리기를 바꾸지 않는다.
  - 모드·값이 실제로 어떤 색·투명도인지는 그리기 드라이버 Dfx_p5s.dll ("DigitalFX Software Driver") 안에 있어 아직 풀지 못했다. 그래서 화면에는 아직 넣지 않았다.
