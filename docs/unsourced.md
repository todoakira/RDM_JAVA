# 아직 원작 근거를 찾지 못한 값 (찾아서 지워 나간다)

원작에서 찾은 값만 쓴다는 원칙에 따라, 코드에 남아 있는 근거 없는 값을 모아 둔다.
찾으면 근거를 적고 이 목록에서 지운다.

| 값 | 자리 | 지금 값 | 메모 |
|---|---|---|---|
| 알려 주는 범위 | world.js CFG.viewX·viewY | 26·36 칸 | 원작은 SetManagementRect (0x468220) 가 가로 ±10, 세로 ±13 칸을 쓴다. 움직임은 ±2 를 더한다 (SendRectMovementInfo 0x468020). 원작은 칸 묶음이 바뀔 때 더하고 빼기도 한다. 그래서 그 방식까지 함께 옮겨야 한다 |
| 길찾기 한도 | CFG.maxPath | 4000 칸 | 원작 클라이언트의 길찾기 함수를 찾아야 한다 |
| 이름 길이 | CFG.maxName | 14 | 원작 계정 서버(새 캐릭터)를 봐야 한다. 맵 서버는 이름을 16 바이트까지 받는다 |
| 대화 길이 | CFG.maxChat | 120 | 원작 클라이언트 입력칸 한도를 찾아야 한다 |
| NPC 대화 거리 | TALK_DIST | 25 | |
| 은행 칸 수 | BANK_SLOTS | 20 | ProcessAddBankItem 0x41ddc0 에서 찾는 중 |
| 시작 자리 | CFG.start, startBeginner | 22 (8,14), 68 (6,45) | |
