# 아직 원작 근거를 찾지 못한 값 (찾아서 지워 나간다)

원작에서 찾은 값만 쓴다는 원칙에 따라, 코드에 남아 있는 근거 없는 값을 모아 둔다.
찾으면 근거를 적고 이 목록에서 지운다.

| 값 | 자리 | 지금 값 | 메모 |
|---|---|---|---|
| 기술 사용의 PK 표시 | pk.js skillGate | 서버의 PK 모드 | ProcessUseSkill 0x43c330: 패킷 길이가 3·0x14 면 클라이언트가 보낸 마지막 바이트, 아니면 IsPKModeOn. 클라이언트(패킷 0xfa)가 그 바이트에 무엇을 넣는지 아직 못 찾음 |
| 돌진 기술의 사람 대상 | world.js castMovingUser | 찍은 사람만 | UseSkillMovingAttack 0x451410 의 사람 갈래에서 가는 길의 다른 사람을 치는지 확인할 것 |
| 기술 칸 d·e·f·g·m | skills.js | 쓰지 않음 | 서버에서 쓰지 않으면 클라이언트(그림·소리)에서 확인 |
| 클라이언트 창 배치 | client.js 0x10010881 근처, ui.js 선택지 창, army.js 창 위치 | 그림에 맞춤 | Main.dll 에서 좌표를 찾을 것 |

## 찾아서 지운 값

| 값 | 원작 근거 |
|---|---|
| 알려 주는 범위 | SetManagementRect 0x468220: 가로 ±10, 세로 ±13 칸 (맵이 22×28 보다 작으면 맵 전체), 걸음은 두 칸 더 (SendRectMovementInfo 0x468020). 서버는 걸음 패킷에 CIS 를 통째로 실어 보내고 따로 넣고 빼는 통지는 없다 (ProcessUserMoving 0x467f40) |
| 길찾기 | 클라이언트 A* 를 그대로 옮겼다 (Main.dll 0x100372c0 · 0x10037180 · 0x10036e50 · 0x10036d20 · 0x10036c80). 한 걸음마다 다시 찾고, 펼치는 횟수 한도는 \|dx\|×맵 너비 + \|dy\|×맵 높이 + 3. 목표 칸을 못 가면 위·아래·왼쪽·오른쪽 순으로 바꾼다 (0x10005780) |
| 이름 길이 | 14 바이트보다 길면 앞 14 바이트만 쓴다 (svIP.exe 0x404abe) |
| 대화 길이 | 입력칸 한도 없음 (_DIRECT_EDIT_DESC+0x7c = −1, Main.dll 0x10076298). 패킷 본문 0x2000 바이트 (Nw200 0x10002f8f) |
| NPC 대화 거리 | 25 미만 (0x406815). 클라이언트는 걸어가지 않고 바로 0x118 을 보낸다 (Main.dll 0x100113ec) |
| 특수기 DP 부족 · 회복 기술 사거리 | 둘 다 알림 없이 끝난다 (UseSkill 0x45e4f6, 0x45ecf0~0x45ed3d). 사거리는 거리 + 막힘 검사 |
| 은행 칸 수 | 20 (ProcessAddBankItem 0x41ddc0) |
| 시작 자리 | 보통 22 (8,14), 초보 68 (6,45) (svIP.exe 0x401725 / 0x4016c9). 시험 서버 설정(+0x343c = 1)이면 42 (234,222,1) (0x404b71) |

## 아직 옮기지 않은 원작 기능 (값을 몰라서가 아니라 아직 손대지 않은 것)

- NPC 이벤트 11~16 군단(아지트·금고·게시판) (ProcessEvent 0x41ee70 의 분기표 0x421f74)
- 배틀 리그 전용 서버 모드 (-BattleArena·-BattleMatch·-BattleServer 로 띄운 서버, BillBattleDB 의 참가비·점수·편·순위·우승 기록). 원작 3944 서버도 이 모드 없이 돌았고, 보통 서버에서는 투기장·대전장에 들어갈 수 없다 (이동 지점은 아무 일 없음, NPC 45 도 아무 일 없음). 이것은 옮겼다.
- 클라이언트: 군단 창의 일부 단추
- 시그너스 돈(SigMoney)은 Tau(5/2)·시그너스 은행·죽을 때 떨어뜨리기로 이미 옮겨져 있음

## 원작 파일에 내용이 없어 우리가 채운 것
- 위치 알림·보물 쪽지(패킷 0x3ef)가 연 웹 쪽: 원작은 board.redmoon.co.kr 의 쪽이었고 rmServer.ini 의 MINIMAP 도 빈 주소. 위치 알림은 맵을 줄여 그리고 자리를 찍고, 보물 쪽지는 원작 주소만 보인다.
- 복권 우편 본문: MDF 의 RMS_ITEMLOTTERY_USEITEM 본문 글이 깨져 있어 복권 번호만 넣었다 (보낸이·제목은 읽힘). 경품표는 data/lottery.json (원작 tblItemLotteryList1 도 운영자가 채우는 표).
- 캐릭터 고르기의 정보 고치기: 원작은 회원 정보 웹 쪽을 열었다 (svIP 의 redmoon_main.asp 주소). 그 쪽이 없으므로 비밀번호 바꾸기로 대신했다.
