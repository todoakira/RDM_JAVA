# 아직 원작 근거를 찾지 못한 값 (찾아서 지워 나간다)

원작에서 찾은 값만 쓴다는 원칙에 따라, 코드에 남아 있는 근거 없는 값을 모아 둔다.
찾으면 근거를 적고 이 목록에서 지운다.

(없음)

## 찾아서 지운 값

| 값 | 원작 근거 |
|---|---|
| 알려 주는 범위 | SetManagementRect 0x468220: 가로 ±10, 세로 ±13 칸 (맵이 22×28 보다 작으면 맵 전체), 걸음은 두 칸 더 (SendRectMovementInfo 0x468020). 서버는 걸음 패킷에 CIS 를 통째로 실어 보내고 따로 넣고 빼는 통지는 없다 (ProcessUserMoving 0x467f40) |
| 길찾기 | 클라이언트 A* 를 그대로 옮겼다 (Main.dll 0x100372c0 · 0x10037180 · 0x10036e50 · 0x10036d20 · 0x10036c80). 한 걸음마다 다시 찾고, 펼치는 횟수 한도는 \|dx\|×맵 너비 + \|dy\|×맵 높이 + 3. 목표 칸을 못 가면 위·아래·왼쪽·오른쪽 순으로 바꾼다 (0x10005780) |
| 이름 길이 | 14 바이트보다 길면 앞 14 바이트만 쓴다 (svIP.exe 0x404abe) |
| 대화 길이 | 입력칸 한도 없음 (_DIRECT_EDIT_DESC+0x7c = −1, Main.dll 0x10076298). 패킷 본문 0x2000 바이트 (Nw200 0x10002f8f) |
| NPC 대화 거리 | 25 미만 (0x406815). 클라이언트는 걸어가지 않고 바로 0x118 을 보낸다 (Main.dll 0x100113ec) |
| 특수기 DP 부족 · 회복 기술 사거리 | 둘 다 알림 없이 끝난다 (UseSkill 0x45e4f6, 0x45ecf0~0x45ed3d). 사거리는 거리 + 막힘 검사 |
| 은행 칸 수 | 20 (ProcessAddBankItem 0x41ddc0) |
| 시작 자리 | 보통 22 (8,14), 초보 68 (6,45) (svIP.exe 0x401725 / 0x4016c9). 시험 서버 설정(+0x343c = 1)이면 42 (234,222,1) (0x404b71) |

## 아직 옮기지 않은 원작 기능 (값을 몰라서가 아니라 아직 손대지 않은 것)

- NPC 이벤트 4 메일, 11~16 군단(아지트·금고·게시판), 45 배틀존 이동 (ProcessEvent 0x41ee70 의 분기표 0x421f74)
- 이벤트 23~26: 시간마다 아이템이 생기는 자리 (0x420e44~0x42107f, GetRandomIIS 분류 100 / 4 / 1·2 반반 / 아무거나). 클라이언트가 어떤 자리에서 이 이벤트를 부르는지 확인할 것
- 이동 이벤트의 투기장(0x84~0x88)·대전장(0xb4~0xbc) 입장 조건 (GetBattleArenaState / GetBattleMatchState, 메시지 0x139·0x14d)
- 아이템 사용 효과 가운데 체력·마력 회복이 아닌 것 (world.js useItem)
- 몬스터: 67·39 아이템 훔치기, 효과 45 반격(몬스터 효과 55), 종류 70·72·모습 98 회복, 84·82·93 의 LoadMop 짝, 순간이동 몬스터가 멈춘 뒤의 범위 기술
- 성장 창(패킷 0x4bd~0x4c1), 중화기 범위 공격(0x1d → DoAttackRange 0x46ccc0), 시그너스 돈(SigMoney)
