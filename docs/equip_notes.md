# 장비 효과 분석 기록 (InitializeEquipmentEffect 0x4352d0)

구현: `server/equip.js`. 사용자 필드: +0x3f5c~0x3f68 = DB 의 근력·정신력·민첩성·기골, +0x37f8 = 레벨, +0x37fc = 직업.

## 칸마다 (14칸, +0x3e48 + 0x10 × 칸)
- 무기 공격(+0x18) → +0x42fc, 방어(+0x1c) → +0x430c, 능력치(+0x20~+0x2c) → +0x4310~+0x431c.
- 7번(무기) 칸이 5번 칸과 같은 물건이면 한 번만 센다. 7번 칸의 +0x55 → +0x4334.
- 등급(+0x54) 1·3 고유 장비: 공격·방어 등이 "DB 능력치 × 레벨 ÷ 수". 분류 1 무기 10종, 분류 3 반지 2종, 분류 6 약 80종 (equip.js 의 K1·K3·K6).
  결과는 무기 공격(+0x42fc), 추가 공격 T+0x30(+0x4300), 기술 공격 값 덤 T+0x34(+0x4304), 기술 피해 덤 T+0x38(+0x4308), 방어(+0x430c).
  나눗셈 마법수 0x6c16c16d = ÷45, 0xd41d41d5 = ÷35.
- 분류 6 의 몇몇 번호는 고유가 아니어도 덤이 있다 (1·8, 10 군단장, 11·12, 14, 17, 18, 23, 26, 28, 35·36·37, 90~98).
- 강화 바이트(+0x3e52~0x3e55)와 성장 등급(GetCurrentGrowthGrade)에 따른 능력치 덤 표가 있으나, 아이템에 강화 정보가 아직 없어 옮기지 않았다.
