# 접속 화면 (Main.dll 0x10007470 분석)

## 첫 화면
- 바탕은 n-if-ch-ba (800×600, "The Eclipse" 판) 이다.
- 단추는 모두 y 513, 높이 62 다. 그림은 세 칸 (y 0·62·124) 이다.
- 단추 자리 (0x100089bb~0x100093c7):

| 단추 | 그림 | x 범위 |
|---|---|---|
| Login | n-if-li-bu | 33~148 |
| New ID | n-if-ni-bu | 157~280 |
| Prolog | n-if-pr-bu | 279~408 |
| Help | n-if-he-bu | 408~545 |
| Credits | n-if-cr-bu | 545~673 |
| Exit | n-if-ex-bu | 673~783 |

- **창:**
  - 로그인 창은 iw-lo-ba (350×151) 이다.
  - 새 ID 창은 iw-id-ba (500×329) 이고, 자리는 (150,126) 이다 (0x10009733).

## 캐릭터 고르기 (0x10015370, 바탕 IF-CO-BA = 대화상자 +0x75e04, 0x10010c8a)
- 칸마다 전신 if-co-* 를 놓는다.
  - if-co-* 는 220×1935 이고, 220×387 다섯 장이다. 0 장은 회색으로 멈춘 그림, 1~4 장은 색이 든 움직임이다.
  - 자리는 칸 0·1·2 가 (49|291|532, 31)~(+220, 418) 이다. 동그라미가 몸 뒤에 온다.
  - 이름 칸은 (x, 370)~(x+218, 416) 이다.
  - 고른 칸만 1~4 장을 돈다 (CxDXCAniSurface, 0,387~220,774 에서 시작).
- 단추는 x 250~550, 높이 24 다 (0x100098a5~0x1000a1d6). 그림은 세 칸 (y 0·24·48) 이다.
  - Game Start 456, Add New Character 480, Delete Character 504, Change User Info 528, Logout 552.

## 캐릭터 만들기 (0x1000a2bf~0x1000ba34, 0x10018bb0, 바탕 IF-CC-BA)
- **얼굴 단추:** if-fa-* 120×120 두 칸 (보통·고름) 이다.
  - 위 줄은 y 16 에 x 16·145·274·404·535 (pi·az·sa·de·pa) 다.
  - 오른쪽 줄은 x 663 에 y 16·146·276·406 (ca·ha·lu·la) 이다.
- **고른 직업의 전신:** if-co-* 의 1~4 장을 (16,146) 220×387 에 돌린다.
- **설명:** 설명 칸 (268,189)~(623,522) 에 Message 0/0/(52+직업) 을 넣는다.
- **그 밖의 자리:** 이름 칸 (395,157)~(560,172), OK (500,540)~(625,570), Cancel (625,540)~(750,570) 이다.
- **색 고르기:** (32,541)~(242,554) 와 (32,560)~(242,573) 은 머리·옷 색 고르기로 보인다.
  - 11가지 색이고, 표 0x100c777c 는 실행 중에 채워진다. if-pa-li·if-pa-in 은 그 표시로 보인다.
  - 머리 if-h0-*·옷 if-c0-* 겹 그림에 그 색을 입힌다.

## 원작과 다르거나 확인 못 한 것
- **단추 그림:** 세 칸의 순서(보통·마우스 위·누름)는 짐작이다.
- **로그인 창:** 화면 위치(225,340)와 OK·Cancel 자리는 짐작이다.
  - 원작 코드에는 너비 350 과 가로 225 가 보이지만, 세로 자리는 다 풀지 못했다.
- **새 ID 창:**
  - ID·비밀번호·비밀번호 확인만 쓴다. 이름·주민번호 등 나머지 칸은 받지 않는다.
  - OK·Cancel 자리는 짐작이다.
- **움직임:** 장 간격 150ms 는 짐작이다.
- **머리·옷 색:** 색 고르기와 겹 그림(if-h0·if-c0)은 아직이다. 색 표가 실행 중에 채워져서 값을 모르고, 우리 판 캐릭터에도 색 값이 없다.
- **이름 칸 글:** 이름 칸에 무엇을 어떻게 쓰는지(레벨 포함 여부)는 확인하지 못했다.
- **시작 위치 고르기:** 우리 판에만 있다.
- **아직 안 함:** Prolog·Credits·Change User Info.
- **지우기:** 확인은 원작의 생년월일 대신 계정 비밀번호로 한다.
- **게임 안 안내 글:** 오른쪽 위 조작 안내와 왼쪽 위 맵·위치 글은 원작에 없어서 기본으로 숨겼다. F12 로 켠다.
