# 이노큘레이터·아이템가드 (시간제 아이템 효과)

구현: `server/inoc.js`, `server/world.js` (useInoc, inocChanged, applyDamage, userEffect, deathPenalty), `server/equip.js`.

## 저장과 상태
- 사용자 +0x4120 에 종류 13 개의 남은 시간(ms)이 있다.
- +0x402c·+0x402e 에 종류마다 2비트 상태가 있다 (종류 0~7 → +0x402c, 8~12 → +0x402e).
- 상태값: 남은 시간 < 30,000 → 1, < 60,000 → 2, 그 밖 → 3, 0 → 꺼짐.
  - 근거: ProcessRegisterUser 0x423e85, 0x42d625.
- 클라이언트는 패킷 0xf9 로 이 비트를 받는다 (0x43a0f0).
  - 1·2 는 곧 끝남을 알린다. 클라이언트는 1 이면 빠르게, 2 면 느리게 아이콘을 깜빡인다 (docs/ui_audit.md 의 이노큘레이터 아이콘 줄).
- 남은 시간은 접속해 있는 동안 흐른 ms 만큼 줄어든다 (OnTimer 0x42e450).

## 쓰기 (UseItem 0x4308c3~0x430d29, 더하기 0x42d5f0)
- 분류 5 아이템:

  | 번호 | 종류 | 시간 |
  |---|---|---|
  | 111~120 | 0~9 | 300초 |
  | 121~130 | 0~9 | 600초 |
  | 148 | 10 | 300초 |
  | 150 | 10 | 600초 |
  | 149 | 11 | 300초 |
  | 151 | 11 | 600초 |

- 분류 6 의 196 아이템가드 → 종류 12, 600초.
  - 이미 켜져 있으면 쓸 수 없다 (0x430cc1).
- 남은 시간 += 초 × 1000. 남은 시간이 40억 이상이면 더하지 않는다.
- 이벤트 서버 행동(0x40e385)도 종류 6 을 5400초 건다. 대본 명령 이름은 아직 찾지 않았다.

## 사람에게 맞을 때 (CMapServerClient::DecreaseHP 0x4394a0)
이노큘레이터 7 을 넣으면서 이 함수 전체를 옮겼다.
1. 줄임 % 를 정한다.
   - 시작은 장비 대인 방어 +0x4378 이다. 묶음 덤과 분류 2·3 장비 덤이며, 최대 90 이다.
   - 맞는 사람이 레벨 1000 이고 공격자가 1000 미만이면 +30 (최대 90).
   - 이노큘레이터 7 이면 +15 (최대 90).
2. 더함 = 공격자 +0x4370 % (장비 묶음 덤)만큼의 피해다.
3. 피해 += 더함. 그다음 줄임만큼 빼되 1 은 남긴다. 최대 2억.

아직 넣지 않은 것:
- 공격자 USERDB +0x854 & 0x30 이면 피해의 1/10 을 더한다. 그 칸이 무엇인지 모른다.
- 마지막 인자가 1 이고 맞는 사람 +0x3f74 > 3 이면 피해를 +0x3f74 ÷ 3 으로 바꾼다. 쓰이는 경로를 모른다.
