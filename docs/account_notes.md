# 계정과 캐릭터 세 칸 (원작 svIP.exe 분석)

원작 로그인 서버 svIP.exe 를 Ghidra 로 풀어 본 것 (프로젝트 /tmp/gh/svip, 심볼은 COFF 심볼표에서 뽑음).

## 확인한 것
- 계정 하나에 캐릭터 **3칸**. 계정 자료 +0x87c 부터 17바이트 이름 3개.
- 새 캐릭터: 이름이 이미 있으면 Message 0/1/17, 빈 칸이 없으면 0/1/3.
- 캐릭터 지우기: 원작은 **생년월일(dd-dd-dd)** 을 맞춰야 하고, 레벨 1001 이상이면 못 지움 (서버 종류 2/3 이면 500). 막히면 0/1/29 (%u 에 한계 레벨).
- 군단장은 못 지움 → 0/1/25. 병사는 군단에서 빠짐 (CArmy::RemoveArmyMember), 편지도 다 지움 (CMailDB::DelAllMail).
- 고르기 화면 글: 0/1/4 "Select your character."

## 우리 판에서 바꾼 것 (원작과 다름)
- 생년월일을 받지 않으므로 **지울 때 계정 비밀번호**로 확인한다.
- 레벨 한계는 1001 (서버 종류 0/1 기준).
- 예전 판(캐릭터 이름 = 로그인)의 저장은 그 이름을 ID 로, 같은 비밀번호로 로그인하면 0번 칸으로 옮겨진다.

## 아직 못 한 것
- 원작 고르기 화면 그림 배치: if-co-ba(동그라미 3개), 얼굴 if-fa-* 240×120 2프레임, if-co-* 220×1935 띠. 배치 코드는 Main.dll 0x10010881 근처. 지금은 임시 배치다.

## 메시지 흐름
login(id,pw,create) → chars(list) → newchar / delchar / select → welcome. 오류는 {t:'lerr', code} 로 Message 0/1 번호를 보낸다.
