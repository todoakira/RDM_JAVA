# 도움말 창과 설정 명령 (Main.dll 분석)

## 도움말 창
- 만들기 0x10081900, 글 채우기 0x10082410. 같은 창 종류가 둘 있다: 게임 객체 +0x78a5c 는 Message 1/0 (로그인 도움말), +0x849ac 는 Message 1/1 (게임 도움말). 0x100105a3 에서 각각 채운다.
- 0번 줄은 제목칸(+0x8ac)에, 1번 줄부터 `:EOF` 줄 앞까지는 여러 줄 글칸(+0x7bc)에 넣는다.
- 바탕 ge-wr-ba 383×297, 닫기 ge-cl-bu (304,263) 62×19.
- 제목칸 (20,47)~(346,69), 색 0xffff. 글칸 (20,70)~(346,255), 색 0x91d7ff, 글꼴 높이 12.
- 스크롤 막대 (349,45) 17×209: 위 iw-it-s1, 아래 iw-it-s2 (y 192), 바탕 iw-ge-s3, 손잡이 iw-it-s4.
- **확인하지 못한 것:**
  - 창의 화면 위치. 만들 때는 (0,0) 이라서, 지금은 화면 가운데 (208,151) 에 둔다.
  - 색은 COLORREF(BGR) 로 읽었다 (본문 #ffd791, 제목 #ffff00).
  - 한 화면에 보이는 줄 수. 지금은 12줄, 줄 높이 15.
  - 로그인 화면 Help 단추(if-he-bu) 의 자리. 지금은 우리 로그인 칸 옆에 둔다.

## 설정 (원작에는 설정 창이 없다)
원작 클라이언트는 설정을 대화 명령으로 바꾼다 (0x10076486 명령 처리):
- `` `대화 `` / `` `chatview `` 켜기|on, 끄기|off, 상태|state, 또는 0/1 여섯 자리.
  - 종류별로 화면 대화 줄에 보일지 정한다 (0x10005f10 의 0x10~0x200).
  - 여섯 자리 순서는 일반, 시스템, 외침, 귓속말, 그룹, 군단이다 (0x1001be96 의 종류 1,6,2,3,4,5).
  - 대화 기록 창(History)에는 언제나 남는다.
  - 바꾼 뒤 0/0/477 형식으로 상태를 보인다 (On 0/0/478, Off 0/0/479).
- `` `음악 `` / `` `music `` 켜기|끄기: 배경음악만 끈다 (0x10005e50).
- `` `효과음 `` / `` `sound `` 켜기|끄기: 효과음만 끈다 (0x10005e70).
- 잘못 쓴 인자일 때 원작이 무엇을 보이는지(0x10077996 경로)는 확인하지 못했다. 지금은 아무 일도 하지 않는다.
- 원작에서 이 설정이 저장되는지는 확인하지 못했다. 지금은 저장하지 않는다.
